# tenacious-assesment-0

## Purpose
This repository contains Assessment 0 for the Ten Academy training program. It serves as an initial project to set up the development environment and demonstrate basic workflow proficiency.

## Getting Started

### Prerequisites
- Git installed on your system
- A code editor (e.g., VS Code, Cursor)

### Setup
1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd assesment-0
   ```

2. Start working on your assessment tasks

## Verification
To verify your setup is working correctly:
1. Confirm you can view this README.md file
2. Check that you can create/edit files in this directory
3. Verify git is working: `git status`
